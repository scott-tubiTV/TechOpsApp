# Backlog Genie space instructions

Space `Backlog (DSA CDP Backlog Model)`. These are the per-table `description` rules pushed to
`core_dev.techops.backlog_snapshot` in the space's `serialized_space` (per-table description is the
field Genie follows; see CLAUDE.md). Keep this file in sync when the live instructions change.

Source: copy of DSA's CDP Backlog Data Model (core_dev.dsa.dsac_cdp_backlog_snapshot). One row per content_id per snapshot date ds.SQL RULES: (1) ALWAYS filter ds = (SELECT MAX(ds) FROM core_dev.techops.backlog_snapshot) unless the user asks for a trend, history or a specific date. Only about 15 daily snapshots exist (from 2026-10-08), so say history is short.(2) A 'title' is one row = one content_id. By default count titles with COUNT(*) (or COUNT(DISTINCT content_id)). Rows are movies and episodes (content_type = 'episode' or 'movie'; there are no series rows). Only count by program when the user explicitly asks for programs or series, using COUNT(DISTINCT program_id) over ALL matching rows. NEVER add is_program_representative = true to a program count: a program counts if ANY of its titles match.(3) Do NOT add filters the user did not ask for (no assessment_status, pipeline_stage, is_creator or window filters unless the question names them). If a question says 'the backlog' without qualification, use all rows in the latest snapshot and state that in the answer.(4) is_program_representative is ONLY for summing fees: sum fees only with is_program_representative = true, otherwise fees are double counted across episodes. Use total_committed_fee_all_territories for total deal value and total_fee for US-only.(5) pipeline_stage values: 'ABF Incomplete', 'ABF Incomplete (regressed)', 'ABF Complete', 'In Refresh', 'Ready to Publish', 'Published'. ABF review queue / ABF backlog = assessment_status IN ('PENDING_REVIEW','INTERNAL_REVIEW'). Exclude creator content with is_creator = false only when the user asks about non-creator or partner content.(6) window_status is the US policy window: 'In Window', 'Not Started', 'Expired', 'No Window'. Non-US windows use non_us_window_status. Never infer a US window with LIKE '%US%'.(7) metadata_status DELETED means the metadata team removed the title from the workflow; treat it like COMPLETE. NULL means not in the tool.(8) Quote column values exactly as they appear. Do not invent meanings for title_priority levels or bucket codes (A1..P3, D0); those are not in this table.
